# JonsonLaunch

Лёгкий домашний экран для Android TV / Google TV в духе tvOS: док с плитками, сетка всех приложений,
живой фон из 6 альбомов (абстракция, пейзажи, автомобили, животные, города, люди), ночной режим,
меню по долгому OK, прозрачность плиток, автообновление с GitHub.

## Установка на телевизор
1. На ТВ включить «Для разработчиков» → «Отладка по сети».
2. `release/install-tv.sh <IP телевизора>` и нажать «Разрешить» на ТВ.
3. В настройках лаунчера → «Обновления» → «Разрешить тихую установку» (один раз).

## Выпуск обновления
`release/publish.sh "что изменилось"` — соберёт, закоммитит и создаст релиз `v<версия>` с APK.
Лаунчеры с включённой «Автоустановкой обновлений» скачают его, проверят подпись и тихо установят,
когда лаунчер уйдёт с экрана.

Сборка: `./build.sh` (Android SDK в `tools/sdk`, не входит в репозиторий).
Ключ подписи `debug.keystore` в репозиторий не публикуется — без него обновления не встанут поверх.

Фоны — фотографии с Wikimedia Commons под свободными лицензиями, авторы в `assets/bg/*/CREDITS.txt`.
